# goit-pycore-hw-06

Об'єктно-орієнтована система керування адресною книгою для CLI-асистента.

## Структура проєкту

- `main.py` — реалізація класів `Field`, `Name`, `Phone`, `Record`, `AddressBook` та демонстраційний приклад використання.
- `test_address_book.py` — модульні тести (`unittest`) для перевірки валідації та всіх методів.

## Запуск

```bash
python main.py
python -m unittest -v
```
